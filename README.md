# 产投华创后台原型 DEMO

当前工作副本对应 **V2.3.0 后台同步修订（2026-10-27）**，以用户提供的 V2.3.0 原型和本轮开发页面为依据，沿用原 DEMO 的视觉风格。原始 Desktop 源码及原始 Axure 文件没有覆盖。

本轮主要补齐资产统计与房源配置、订单签约价、合同宽限期与预览、三种租户交互方式、工作台和临时收款。管理人支持多选且**仅作记录**，不增加签约权限；旧“管理人可以发起签约”的要求作废。记账本继续停用，移动端及用户红框排除的系统菜单不在本轮更新范围。

逐项核对与演示限制见上级目录的 [V2.3.0后台同步核对清单（20261027）](../V2.3.0后台同步核对清单（20261027）.md)。`docs/prototype-sync/`、旧需求规格书及 2026-10-26 压缩包保留为历史资料，其中旧 404、旧版本及旧服务端范围描述不作为本轮结论。

## 项目组成

- `packages/admin`：本轮更新的后台页面。
- `packages/server`：本地 API、SQLite 与演示业务流程；本轮有必要的订单、合同及待办查询增量。
- `packages/mobile`：原有移动端源码，本轮未修改页面。

## 首次运行：新建本地演示环境

使用 Node.js 22.12 或更新版本及随附 npm。在本源码副本根目录打开 macOS 终端，执行：

```bash
cp -n packages/server/.env.example packages/server/.env
npm ci
npm run db:migrate
npm run db:seed
npm run dev:admin
```

这是**新演示库**的准备步骤。已有 `.env` 不覆盖；已有本地业务资料先备份数据库和附件，再决定是否初始化，不要为日常启动重复执行种子脚本。`db:migrate` 会先为不存在的本地 SQLite 创建空文件，再按当前结构同步并生成 Prisma 客户端；不会截断已有数据库。种子脚本用于生成虚构演示资料。

环境文件默认使用本地 SQLite。数据库地址、服务端口及演示密钥的配置项见 `packages/server/.env.example`，不需要生产服务凭据。

## 已准备好环境后的日常启动

```bash
npm run dev:admin
```

默认地址：

- 后台：`http://localhost:5174/`；前端端口占用时会顺延，以终端显示为准。
- 服务端健康检查：`http://localhost:8787/health`。

`dev:admin` 同时启动后台和本地服务端。若修改服务端端口，还需同步设置后台的 `VITE_API_PROXY` 指向该服务端。退出时在终端按 `Ctrl+C`。

如需同时启动原有移动端：

```bash
npm run dev
```

移动端默认 `http://localhost:5173/`，同样可能因占用顺延。本轮后台评审只需 `dev:admin`。

## 本轮重点入口

- **资产管理 → 资产列表**：项目筛选、四项面积统计、房源配置四分类；协议定价与对外价格分别维护。可出租与上架分开，收款方、门店、坐落、图片和价格的上架前置继续检查。
- **订单管理**：修改订单签约价，单房与合并多房逐套核对协议价下限；价格保存后进入合同配置。
- **资产管理 → 合同管理**：四种有效模板宽限期默认 0；新建及配置入口可预览草稿，提供三种租户交互方式；详情内查看账单。
- **工作台 → 待办中心**：十类待办卡片、刷新、分页和业务定位；计数采用当前可识别的本地业务资料。
- **临时收款 → 临时收款列表**：新增、查询、详情、付款码及本地演示状态操作。

## 数据与演示边界

订单、合同和原有业务保存在本地服务端 SQLite。资产补充资料、住建维护、部分补充目录、临时收款等保存在当前浏览器的独立版本化记录中；更换 `localhost`/`127.0.0.1`、端口、浏览器或清除站点数据后，这些资料不会自动跟随源码或数据库迁移。

新合同的推送签署、签署完成、付款完成及临时收款支付均有本地演示标识，不代表真实签署、短信或支付成功。临时收款二维码在浏览器本地生成，仅编码随机演示编号，不含租户资料，不向第三方二维码服务发送信息。请用虚构资料评审。

资产“立即同步”仅刷新本地资料；住建核验和上架场景不代表真实外部回执。管理人多选仅记录资料，不改变账号权限。

工作台“退租待审批”“换房待跟进”未取得明确可识别来源，显示“— / 暂无待办数据”；不会根据退租签字等待或换房历史猜测待办。其余分类按当前可读取记录计算，加载失败有重试提示；操作只定位原业务页面。

资产展示价格和临时收款支持两位小数。订单改价仍兼容原 DEMO 的整数元字段；小数协议价的最低可填整数向上取整。该兼容方式不作为正式产品的金额规则。

## 构建检查

在源码根目录执行：

```bash
npm run build:admin
npm run build:server
```

后台包含运行时依赖 `qrcode` 及类型依赖 `@types/qrcode`，已记录在包清单和锁文件中；付款码打开时才加载二维码模块。仅复制编译后的页面或某几个组件不能替代完整源码与依赖安装。
